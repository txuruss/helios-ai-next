# Client Acquisition Readiness

## Summary

A checklist for deciding whether Helios AI is ready to begin outreach. The bar is **"good enough to sell," not "perfect."**

## Current status

`Ready enough for outreach` — most criteria are met; the open item is a production audit-submission test (see [[Next Steps]]). That production test is `Needs testing`.

## Ready to begin outreach if all are true

- [ ] Website loads correctly
- [ ] Main CTA works
- [ ] Audit form submits successfully (test on **production**)
- [ ] Contact email is visible (`hello@heliosai.agency` — see [[Email Setup]])
- [ ] Offer is clear
- [ ] Pricing or starting offer is clear enough (see [[Pricing]])
- [ ] There is a way to manually follow up with leads
- [ ] You can explain the offer in one sentence
- [ ] A basic demo or walkthrough can be shown

## Do NOT block outreach because

- PayPal is unfinished ([[PayPal]])
- Relevance AI is unfinished ([[Relevance AI]])
- The backend is not perfect
- The dashboard is not fully automated
- All future features are not complete

**The first client can be handled manually if needed.**

## Key decisions

- Validate demand before perfecting automation. (See [[Decision Log]] and [[Risks]].)
