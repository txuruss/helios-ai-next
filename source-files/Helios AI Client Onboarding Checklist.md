# Helios AI Client Onboarding Checklist

Run this immediately after a client agrees to work with Helios AI. It moves a signed client from "yes" to "ready to build."

---

## Client onboarding goal

Get everything needed to start the build — payment, agreement, access, and complete business info — so delivery can begin without back-and-forth. Onboarding is complete only when the build can start the same day.

---

## Pre-onboarding requirements

- [ ] Package confirmed (Starter / Booking OS / Ops Center)
- [ ] Price and billing terms agreed (setup + monthly)
- [ ] Launch deadline discussed
- [ ] Main point of contact identified
- [ ] Approval contact identified (who signs off on the build)

---

## Payment confirmation checklist

- [ ] Setup fee invoice sent (PayPal)
- [ ] Setup fee paid and confirmed
- [ ] Monthly retainer set up / scheduled
- [ ] Billing email recorded
- [ ] Payment confirmation logged in client record

> Do not start the build before the setup fee clears.

---

## Contract or agreement checklist

- [ ] Service agreement sent
- [ ] Scope matches the purchased package
- [ ] Revision and support terms included
- [ ] Agreement signed by client
- [ ] Signed copy stored

---

## Client intake checklist

- [ ] [[Helios AI Client Intake Form]] sent to client
- [ ] Intake form returned and complete
- [ ] Missing fields chased (use Missing information message)
- [ ] All services, prices, and durations captured
- [ ] FAQs collected

---

## Account access checklist

Request only what the package needs:
- [ ] Website access or ability to add the chat widget embed
- [ ] Booking system access / booking link (Cal.com or current tool)
- [ ] WhatsApp Business number + access (Booking OS / Ops Center only)
- [ ] Email address for owner notifications
- [ ] Logo and brand assets (if needed)

---

## Brand and tone checklist

- [ ] Preferred assistant tone confirmed (friendly / professional / casual / formal)
- [ ] Greeting style agreed
- [ ] Words or phrases to avoid noted
- [ ] Brand name spelling and pronunciation confirmed

---

## Service information checklist

- [ ] Full service list with descriptions
- [ ] Price per service
- [ ] Duration per service
- [ ] Add-ons or packages noted
- [ ] Services the business does NOT offer noted (to prevent wrong answers)

---

## Booking process checklist

- [ ] Current booking method documented
- [ ] Booking link confirmed (or to be created)
- [ ] Availability and hours confirmed
- [ ] Deposit policy confirmed
- [ ] Cancellation / rescheduling policy confirmed
- [ ] Walk-in handling confirmed

---

## FAQ collection checklist

- [ ] Top customer questions collected
- [ ] Pricing questions answered
- [ ] Location / parking / access questions answered
- [ ] Policy questions answered
- [ ] Answers approved by client (see [[Helios AI Client FAQ Builder]])

---

## Notification setup checklist

- [ ] Owner notification channel confirmed (email / WhatsApp / both)
- [ ] Notification recipients listed
- [ ] Notification triggers agreed (new lead, booking request)
- [ ] Quiet hours / preferences noted

---

## Approval contact checklist

- [ ] Single person responsible for approvals identified
- [ ] Their contact details confirmed
- [ ] They understand they sign off on FAQs, flows, and launch
- [ ] Backup approver noted (optional)

---

## Timeline confirmation checklist

- [ ] Build start date set
- [ ] Internal target launch date set
- [ ] Client-facing launch date communicated
- [ ] Dependencies the client owes us listed with due dates

---

## Red flags before starting delivery

- Setup fee not paid
- Agreement not signed
- No clear approval contact
- Incomplete service or FAQ info
- Client expects features outside the purchased package
- No access to website / booking / WhatsApp where required
- Unrealistic launch deadline given missing info

If any red flag is present, pause and resolve it before building.

---

## Client onboarding completion criteria

Onboarding is complete when:
- [ ] Payment confirmed
- [ ] Agreement signed
- [ ] Intake form complete
- [ ] All required access granted
- [ ] FAQs and services confirmed
- [ ] Approval contact and timeline set
- [ ] No open red flags

Only then move to [[Helios AI System Setup Framework]].
