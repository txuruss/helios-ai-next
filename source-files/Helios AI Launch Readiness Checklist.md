# Helios AI Launch Readiness Checklist

Confirm a client system is ready to go live. Nothing launches until every relevant item passes and the client signs off.

---

## Launch readiness goal

Verify the system delivers the core outcome — reply fast, answer FAQs, capture leads, notify the owner, route to booking — reliably and on the client's channels, before going live.

## Client information confirmed

- [ ] Business name, type, location correct
- [ ] Services, prices, durations correct
- [ ] Opening hours correct
- [ ] Policies (cancellation, deposit, payment) correct
- [ ] Approval contact confirmed

## Package scope confirmed

- [ ] Package matches what was sold
- [ ] All in-scope components built
- [ ] No out-of-scope features added by mistake

## Services confirmed

- [ ] Assistant knows every offered service
- [ ] Assistant never promises services not offered

## FAQs confirmed

- [ ] All required categories covered
- [ ] Answers approved by client
- [ ] Escalation rules set

## Booking link confirmed

- [ ] Booking link works and is correct
- [ ] Opens correctly on desktop and mobile
- [ ] Points to the right calendar / services

## Assistant prompt tested

- [ ] Greeting correct and on-tone
- [ ] FAQ answers accurate
- [ ] Fallback / escalation works
- [ ] No invented information

## Website chat tested

- [ ] Widget loads on all key pages
- [ ] Answers FAQs correctly
- [ ] Captures leads
- [ ] Booking link shares correctly

## WhatsApp tested, if included

- [ ] Number connected and verified
- [ ] Greeting and FAQs work
- [ ] Booking flow works
- [ ] 24-hour window handling confirmed
- [ ] (Skip if Starter — WhatsApp not included)

## Lead capture tested

- [ ] Name + contact captured
- [ ] Enquiry type and source captured
- [ ] Lead appears in the dashboard

## Owner notifications tested

- [ ] Notification fires on new lead
- [ ] Notification fires on booking request
- [ ] Correct channel (email / WhatsApp / both)
- [ ] Format is clear and complete

## Dashboard tested

- [ ] Client can log in
- [ ] Leads display correctly
- [ ] Status options work
- [ ] Notes can be added

## Mobile view tested

- [ ] Website chat works on mobile
- [ ] Booking link works on mobile
- [ ] Notifications readable on phone

## Client approval received

- [ ] FAQ approval signed off
- [ ] Booking flow approved
- [ ] Chat test approved
- [ ] Written go-live approval received

## Final launch checklist

- [ ] All relevant items above pass
- [ ] Embed code live on the client's site
- [ ] WhatsApp live (if included)
- [ ] Dashboard access confirmed with client
- [ ] Handoff pack delivered
- [ ] Launch completed message sent

## Post-launch monitoring checklist

- [ ] Watch first real conversations (first few days)
- [ ] Confirm first real lead captured + notified
- [ ] Fix any wrong answers immediately
- [ ] Log issues and optimization notes
- [ ] Schedule monthly review (Booking OS / Ops Center)

## Launch blockers

Do **not** launch if any of these are true:
- Setup fee unpaid
- FAQs not approved
- Booking link broken
- Lead capture not writing to dashboard
- Owner notifications not firing
- Required channel not connected
- No client sign-off
